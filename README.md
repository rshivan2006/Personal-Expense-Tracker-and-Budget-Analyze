# Personal Expense Tracker and Budget Analyzer

## Overview

The Personal Expense Tracker and Budget Analyzer is a frontend web application designed to help users manage their daily expenses and monitor their spending habits. Built using HTML, CSS, and JavaScript, it provides an interactive dashboard to record transactions, analyze category-wise expenses, set monthly budgets, and track financial activities.

## Features

- **Expense Management:** Add, view, and delete expense transactions.
- **Dashboard:** View total expenses, transaction count, highest-spending category, and budget alerts.
- **Category-wise Analysis:** Monitor spending across Food, Transport, Shopping, Bills, Entertainment, Health, Education, and Other categories.
- **Budget Management:** Set monthly spending limits for individual categories.
- **Budget Alerts:** Identify categories that exceed their allocated budgets.
- **Monthly Summary:** Analyze expenses for a selected month.
- **Visual Charts:** Display spending patterns using doughnut and bar charts.
- **Search and Sorting:** Search transactions and sort them by date or amount.
- **CSV Export:** Export monthly transaction records for further analysis.
- **Local Storage:** Save expenses and budgets in the browser.
- **Responsive Design:** Access the application on desktop, tablet, and mobile devices.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Chart.js
- Browser Local Storage
